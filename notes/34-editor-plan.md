# Редактор книги: что делаем

## 1. Сразу

- **Обрезанная «р» в «стр. 24».** У подписи жёстко задана высота 14 px, а строка шрифта занимает около 17 px. Ставим минимальную высоту вместо жёсткой и проверяем такие же места на других экранах.
- **Enter в подписях.** Enter переносит строку, над клавиатурой отдельная кнопка «Готово» с галочкой. Если в макете помещается 2 строки, на третьем Enter появляется подсказка «тут помещается 2 строки».
- **Цены.** Сейчас доплата за разворот в приложении неверная. Должно быть:

| Тариф | От | Фото | Страниц | За разворот |
|---|---|---|---|---|
| Lite | 70,00 р. | 24–480 | 24–160 | +0,90 р. |
| Classic | 81,00 р. | 20–180 | 20–60 | +1,50 р. |
| Premium | 100,50 р. | 10–180 | 10–60 | +3,50 р. |

- **Скорость загрузки.** Сейчас редактор с фото по 10 МБ открывается через 65–70 секунд, цель — меньше 20. Редактор ждёт, пока загрузятся все фото и соберётся книга. Ещё есть подозрение, что фото из «Файлов» уходят без сжатия.
  1. Замерить время по этапам: сжатие, сеть, сборка.
  2. Сначала отправлять маленькие копии по 500–600 px. Серверу их хватает для раскладки, и редактор открывается за 10–15 секунд.
  3. Копии для печати по 3000 px догружать в фоне со строкой «Фото для печати: 12 из 40». «Заказать» ждёт, пока они загрузятся.
  4. Начинать загрузку сразу после выбора фото, пока человек выбирает тариф и пишет название.

## 2. Обложка и страницы

- **Обложка идёт отдельным разворотом первой:** задняя обложка, корешок, лицевая. Её нельзя перетаскивать. По желанию на лицевую обложку выводится название черновика.
- **Страницы добавляются по одной:** кнопка «+ Страница» в конце и «Вставить после» в меню страницы. Цена меняется за разворот, поэтому:
  - при чётном числе страниц на кнопке «+ Страница · +0,90 р.»;
  - при нечётном — «бесплатно, на развороте есть место»;
  - при нажатии «Заказать» с нечётным числом: «Последняя страница останется пустой, разворот уже оплачен. Добавить?»
- **Развороты не разрываются.** Вставка одной страницы сдвигает все следующие страницы, и фото «на разворот» может разъехаться на два листа. В этом случае предлагаем добавить ещё одну страницу или сделать это фото обычной страницей.

## 3. Порядок страниц

- Зажал страницу и тащишь **прямо в ленте**, остальные расступаются, у края экрана лента сама прокручивается.
- Сетка «Порядок страниц» остаётся, но открывается по кнопке, для толстых книг.
- При первом открытии черновика сверху один раз появляется плашка: «Зажмите страницу и перетащите, чтобы поменять порядок».

## 4. Назад / вперёд

- Две стрелки ↶ ↷ в шапке вместо одиночного «Отменить».
- В историю попадает всё: фото, раскладки, текст, шрифт, размер, цвет, порядок страниц, добавление и удаление страниц, фон, рамки, исправления ИИ.
- Одно действие — один шаг. Ползунок записывается, когда отпущен палец, а исправление ИИ — одним шагом, сколько бы страниц оно ни поменяло.
- После удаления фото или страницы остаётся короткая плашка «Отменить». Это та же история, просто кнопка ближе к пальцу.
- История хранит около 50 шагов, пока открыт черновик.

## 5. Текст

- Готовые стили строк: «Заголовок + подпись», «Только подпись», «Цитата».
- **Размер:** по умолчанию один ползунок на весь текст. Нажал на строку — ползунок двигает только её. Кнопка «По умолчанию» появляется, когда размер изменён.
- **Цвет — две строки кружков:**
  - основные: белый, чёрный, пыльная роза, шалфей, дымчато-голубой;
  - из фото этой страницы: 2 светлых и 3 тёмных.
  - Если цвет плохо читается на фоне, показываем подсказку или подставляем полупрозрачную плашку под текст.
- Шрифты — те 3–4, что уже есть.

## 6. Оформление

- **Вопросы в начале — один экран, везде уже выбран вариант по умолчанию:**
  1. Какие фото: лучшие / почти все / все.
  2. Размер фото: крупно / средне / много мелких.
  3. Фон: белый / бежевый / тёмный / «ИИ подберёт».
  4. Украшения: нет / немного / тематические стикеры.

  Внизу кнопка «Собрать книгу» и вариант «Пусть ИИ решит сам». Фон потом меняется в редакторе.
- **Рамки:** без рамки, белые поля, тонкая линия, полароид, скруглённые углы. Есть переключатель «Ко всем страницам».
- **Стикеры:** берём бесплатные наборы с открытой лицензией (море, день рождения, свадьба, путешествие, Новый год, дети, осень). ИИ сам выбирает набор по фото и ставит по 1–2 стикера так, чтобы они не закрывали лица и не заходили за линию обреза. Со стикером можно сделать три вещи: сдвинуть, изменить размер, убрать.
- **Новые шаблоны страниц:** фото с широкими полями, маленькое фото с подписью, фото на всю страницу с подписью поверх, фото и колонка текста, заголовок над фото. Над списком переключатель «1 · 2 · 3 · 4 фото».
