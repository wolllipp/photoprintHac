# Базовая линия: текущий путь заказа в picPac

Задача: [#1](https://github.com/wolllipp/photoprintHac/issues/1). Ответственные: Ваня, Алеся.
Зачем: цифры «было» для питча и критериев A1, A2, A7. Без них «сократили путь» — просто слова.

## Важно перед замером
- **Не оформлять заказ до конца.** В корзине сайт предупреждает: «заказ автоматически отправится на печать», отменить нельзя. Останавливаемся на экране выбора оплаты.
- Включить **запись экрана** iOS (Пункт управления → Запись экрана). По записи потом спокойно считаем тапы и время, не отвлекаясь во время замера.
- Подготовить на телефоне **тестовый альбом из 40 фото** (разные: портреты, группы, пейзажи, пара смазанных, пара дублей, 2–3 скриншота из мессенджера). Тот же набор потом используем для демо A1.
- Каждый сценарий проходить **2 раза** и брать лучший результат: первый проход — знакомство с интерфейсом.

## Что считаем
| Метрика | Как |
|---|---|
| Время | от тапа по иконке приложения до экрана выбора оплаты |
| Тапы | все касания, включая «назад» и ошибочные |
| Экраны | число разных экранов по пути |
| Рамки | сколько рамок в книге и сколько заполнено вручную |
| Тупики | где пришлось искать, возвращаться, где было непонятно |
| Предупреждения | показал ли редактор что-то о качестве фото и обрезке |

### Правка текста (видео «ноут текст», 3:46, сайт на ноутбуке, шаблон «moments»)
Книга уже собрана автозаполнением, меняются только подписи.

| # | Блок | Время | Заметки |
|---|---|---|---|
| 1 | Обложка: «2025\|26» → «Выпуск\|24» | 0:00–0:48 | ≈48 с: две части строки разного цвета, правятся по отдельности; надпись мелкая, пришлось увеличивать масштаб |
| 2 | Разворот 1: подпись под фото | 0:51–1:21 | ≈30 с |
| 3 | Разворот 3: короткая подпись | 1:24–1:33 | ≈10 с |
| 4 | Разворот 5: длинная подпись | 1:36–3:03 | **≈1 мин 27 с**: текст уехал за край страницы одной строкой, индикатор «Ошибки» стал красным; блок пришлось двигать, растягивать и переносить вручную |
| 5 | Разворот 7: подпись | 3:09–3:30 | ≈21 с |
| 6 | Предпросмотр → утверждение | 3:36–3:42 | |

**Итого:** **5 подписей за ≈3,5 мин**, в среднем ≈40 с на подпись. Остальные 8 из 13 текстовых блоков шаблона («Настроить текст в проекте (13)») не тронуты. Если подписать все, по той же скорости выйдет **≈8–9 мин** только на текст.

**Что мешает:**
- Текстовый блок не переносит строки сам: длинная подпись уезжает за край, и это видно только по красному индикатору «Ошибки».
- Мелкий шрифт, без увеличения масштаба не попасть курсором.
- Стилизованная надпись на обложке состоит из нескольких кусков, каждый правится отдельно.
- Подсказок, что писать, нет: в шаблоне остаётся «Тут текст — привет...».

В приложении (проход 2) 5–6 коротких подписей поменяли за ≈48 с, но там это были одно-два слова.

**Общие проблемы во всех каналах:**
1. Сколько фото нужно, заранее не сказано (49, 59, больше 40 — зависит от шаблона). Узнаёшь по ошибке «Пустые фоторамки» или по повторам.
2. Фото приходится загружать несколькими заходами.
3. Вход или регистрация прерывают сборку в середине пути.
4. Предупреждения (пустые рамки, повторы, плохое качество) появляются только на «Заказать», а не по ходу.

## Наблюдения
- **Где было непонятно:**
  - Сколько фото нужно для книги, заранее не сказано. Узнаёшь только на «Заказать» через ошибку «Пустые фоторамки», после этого ещё 2 цикла загрузки.
  - Почему не активна кнопка «Зарегистрироваться» (видео 1).
  - Индекс при доставке: сайт его не подставляет по адресу, пришлось искать в Google.
- **Что раздражало:**
  - Выбор фото по одному в галерее iOS: ≈2 мин на 49 фото.
  - webp не поддерживается, а ошибку видно только после загрузки.
  - После регистрации сайт перекидывает на главную, и путь к корзине теряется.
  - Регистрация обязательна: 5 полей, 2 обязательные галочки и капча; входа по телефону/SMS нет.
  - Окно «Сохранение дизайна» посреди работы.
- **Что понравилось и стоит сохранить:**
  - Авторасстановка фото по разворотам.
  - Оценка качества у каждого фото: звёзды и «Хорошее качество».
  - Зона возможной обрезки в редакторе печати.
  - Предпросмотр с границей безопасности.
  - Загруженные фото сохраняются, и для второго заказа их не нужно загружать заново.
