## 1. Перед запуском — обязательно (иначе сервер не стартует)

```bash
cd services/api
uv run python -c "import secrets; print('JWT_SECRET=' + secrets.token_urlsafe(48))" >> .env   # свой секрет, ≥ 32 символов
uv run alembic upgrade head        # новая миграция c4e8a2b7d913 (ключ повтора заказа)
uv run python -m app.seed          # демо-аккаунт +375 29 700-00-00 с 350 пиками (только при DEMO_MODE=true)
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- В `.env` должен быть `DEMO_MODE=true` — иначе код 0000 не принимается и вход по SMS выключен.
- Приложение: `cd apps/mobile && npm install && npx expo start --lan`. Если в сети несколько адаптеров (VPN, WSL), задать адрес явно:
  `REACT_NATIVE_PACKAGER_HOSTNAME=<ip>` и `EXPO_PUBLIC_API_URL=http://<ip>:8000`.
- После `git pull` в приложении — `npm install`: добавлены `expo-file-system`, `expo-image-manipulator`, `expo-media-library`.
- Старые токены в приложении больше не принимаются (новый секрет) — приложение само начинает как гость, войти заново.
