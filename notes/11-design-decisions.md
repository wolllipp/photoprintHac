# Дизайн: что сделали и почему

Дата: 08.11. Задачи: [#21 R1](https://github.com/wolllipp/photoprintHac/issues/21), [#22 R2](https://github.com/wolllipp/photoprintHac/issues/22), [#24 R3](https://github.com/wolllipp/photoprintHac/issues/24).

## 1. Сайт picpac.by
- **Аудит текущего сайта:** [notes/10-site-audit.md](10-site-audit.md) — около 30 проблем: тонкий шрифт, контраст коралловых кнопок 3,89 (норма 4,5), перегруженная шапка, 11 противоречий в данных, форма параметров до того, как клиент видит книгу.
- **Пробовали три версии главной** (`design/site/`):
  - v1 — Manrope + Lora, своя структура → не понравились шрифты;
  - v2 — в стиле apple.com (системный шрифт, плитки) → отклонено: потерялась структура picPac;
  - **v3 (принята)** — `design/site/index.html`: **структура текущего сайта** (служебная строка, шапка с продуктами, первый экран, «Топ продуктов», «С нами создают», «Вопросы и ответы», преимущества, подвал), но современное исполнение.
- **Решения v3:** шрифт **Jost** (современный геометрический, близкий к текущему); фирменные цвета, у кнопок коралловый на тон глубже ради контраста (`#B84F4B`, 4,93); 6 продуктов сгруппированы в «Фотопечать ▾» и «Фотокниги ▾», чтобы пункты меню не переносились; тексты без противоречий (страницы вместо листов и разворотов, одно правило по браку, «до 3 рабочих дней + доставка»).
- **Дальше:** пересмотр и доработка сайта — Илья (#24), ревью — Ваня.

## 2. Приложение: путь пользователя
Файл: `design/app/journey.html` — 8 экранов iPhone в ряд, как промо-экраны App Store.

**Источники стиля:**
- **mera** (наш крипто-проект, `~/Developer/crypto-analytics-app`): интерфейс в стиле iOS — групповой фон, белые карточки с большим скруглением, крупные заголовки, круглые действия, подсказки с заливкой, SF Pro, цвет только для состояния. Подача экранов на пастельных карточках.
- **Qalta** (AI-трекер расходов): голос вместо форм, минимум нажатий.
- **Яндекс Go**: шторка над сценой, тарифы лентой, оплата чипом, живой статус.
- **Цвета — picPac:** бежевый фон вместо серого iOS, коралловый — действия, бирюзовый — «всё хорошо», тёмный серо-зелёный — второстепенное.

### Правила списков на главной
- «Мои проекты» — **без карточки**: строки на фоне, разделены тонкой полупрозрачной линией.
- Слева — **иконка без подложки, подобранная автоматически по теме альбома** (тема берётся из Story Mode или выбранного шаблона):

| Тема | Иконка |
|---|---|
| Ребёнок, первый год | коляска |
| Свадьба | кольца |
| Путешествие | самолёт |
| Выпускной | шапочка выпускника |
| Новый год | ёлка |
| Love story | сердце |
| Семья | дом |
| Крещение | голубь |
| Тема не определена | иконка типа продукта (книга, фотопечать, общий альбом) |

- **Цвет иконки — по типу продукта:** фотокнига — коралловый, общий альбом — бирюзовый. Иконка отвечает «про что», цвет — «что это».

### Экраны
1. **Главная** — «Фото уже ждут книгу»: черновик из галереи (Карелия, 214 фото), действия, мои проекты, панель ввода.
2. **Опишите книгу** — запрос словами или голосом → «Поняли так».
3. **Автосборка** — «38 из 214», плитки «−41 дубли / −17 смазанные / −23 скриншоты», любое фото можно вернуть.
4. **Книга и цена** — сцена с разворотом и меткой «Лица в кадре», шторка с тарифами Lite / Classic / Premium.
5. **Оформление** — мой пункт выдачи, чип оплаты «•• 4242», «проверено перед печатью».
6. **Отслеживание** — «Печатаем», полоса этапов, живая строка с производства, история этапов.
7. **Экран блокировки** — Live Activity и уведомление «Макет проверен».
8. **После заказа** — чат, фото брака, перепечатка без пересылки.

**Связь с треком 1:** живая строка «готово 6 из 12 разворотов» и этапы заказа берутся из производственных данных Insight — это видимая клиенту часть сквозного сценария.

## Ограничения
- Фото — градиентные заглушки, цены и данные иллюстративные (цены Lite и Premium за 24 страницы условные).
- Это статичные макеты, не кликабельный прототип.
- Перенос в React Native — по правилам из notes/01-concept.md, раздел 11.
