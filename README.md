# picPac One

**Одна система от фото клиента до решения руководителя.**

Проект команды для Space Hackathon с «Великим камнем» и ООО «Фотопринт» (сервис [picPac.by](https://picpac.by)), 11–13 ноября 2026. Закрываем все три трека хакатона одной связанной системой, а не тремя отдельными прототипами.

## Суть

| Часть | Трек | Что делает |
|---|---|---|
| **picPac** — приложение и сайт для клиентов | 2. Мобильный канал заказа | Собирает фотокнигу сама: из фото в телефоне или по описанию словами. Проверяет качество и обрезку лиц до оплаты. Показывает, на каком этапе заказ. |
| **picPac Insight** — данные и дашборд | 1. Управленческая платформа | Связывает финансы, клиентов, производство и кадры. Находит отклонение, показывает его причину и фиксирует решение с ответственным и сроком. Проверяет по данным, помогло ли решение. |
| **picPac Ассистент** — AI-помощник | 3. Защищённый AI-помощник | Отвечает руководителю на вопросы о бизнесе со ссылками на источники, готовит встречи по отклонениям, ведёт протокол и задачи. Тот же движок в роли «клиент» отвечает покупателям круглосуточно — без доступа к данным компании. |

Все три части работают на общих данных. Заказ из приложения попадает в аналитику, отклонение разбирает ассистент, решение становится задачей, а его эффект проверяется по тем же данным. **Весь AI работает в локальном контуре:** фото клиентов и данные компании не уходят во внешние сервисы.

## Ценность

**Для клиентов picPac**
- Фотокнига без ручной раскладки: сейчас каждое фото вставляется в рамку вручную.
- Ни одного обрезанного лица: проверка кадра до оплаты, а не после печати.
- Понятная цена и срок сразу, статус заказа как у такси.
- Брак — по фото дефекта, без пересылки книги обратно.
- Ответы круглосуточно (сейчас поддержка с 9 до 21 и без телефона).

**Для «Фотопринта»**
- Короче путь до заказа — меньше брошенных корзин.
- Меньше брака и претензий за счёт проверки до печати.
- Руководитель видит причину отклонения сразу, а решения не теряются в почте и чатах.
- Единый справочник продуктов: на сайте сейчас 11 противоречий (сроки, допуски, единицы объёма, условия брака).
- Новые клиенты через общий альбом по QR-коду (выпускные, свадьбы) и реферальную программу.
- Данные и модели внутри контура компании.

Цифры эффекта на питче — только измеренные. Базовая линия текущего пути заказа: [#1](https://github.com/wolllipp/photoprintHac/issues/1).

## Стек

- **Приложение:** React Native (Expo). **Сайт и Insight:** Next.js. Общие токены дизайна.
- **Бэкенд:** Python + FastAPI, один сервис с модулями. **БД:** PostgreSQL + pgvector.
- **Модели:** локально через Ollama (LLM 7–8B), Whisper для встреч, лёгкие модели для лиц и качества фото.

Подробно: [notes/07-architecture.md](notes/07-architecture.md).
